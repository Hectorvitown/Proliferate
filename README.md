# Proliferate
A personal project, trying to bring the professional graphic design to Linux... Natively... And Free

Hello, this is me Hector V.
My main interest with Proliferate is to create a software similar to Affinity, I've grown tired of people saying the Linux has no potential in the professional Graphic Design.

Unfortunaly, I'm no real developer, but I will try to do my best to bring this program to life.
